Getting started

Tutorial

Build a small real site end to end — one concept per part.

Across seven short parts, you'll build Studio Plié — a small site for a paper-folding studio: a home page, a notes section, a gallery. Each part adds exactly one capability to the same project, so by the end you've touched every corner of Kirigami on something real, not seven disconnected snippets.

Assumes you've done install — everything else starts from here.

  1. Setup

    kiri create, the folder layout, kiri serve.

  2. Pages & layout

    Three pages, a shared header/footer, PHPDOC.

  3. Content

    Markdown, a YAML data file, @content.

  4. Styles & scripts

    Retheming with canva, dark mode, the managed <head>.

  5. Images

    The image autogenerator — a hero and a gallery.

  6. SEO

    The seo: block: meta tags and JSON-LD, per-page overrides.

  7. Deploy

    kiribuild, GitHub Pages, kiri export.
