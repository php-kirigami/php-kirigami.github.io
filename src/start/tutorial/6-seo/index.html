SEO

Two config blocks and a per-page override, and the whole head is handled.

  1. Turn metadata on

    Two blocks in kirigami.yaml, both fine empty:

    
                                meta: {}
                                jsonld: {}

    meta: derives <title>, the description, Open Graph, Twitter Card, the canonical link, and the favicon tags from the kirigami: block plus each page's PHPDOC — nothing to write by hand in header.php. jsonld: does the same for a schema.org <script type="application/ld+json"> block. Drop favicon.ico and apple-touch-icon.png in src/ and they're picked up automatically.

  2. Override per page

    A page's own PHPDOC wins over the project-wide defaults:

    
                                /**
                                 * @title           The first pleat
                                 * @meta_description How Studio Plié got its name.
                                 * @meta_image      images/fold-01.jpg
                                 */

    A tag header.php already writes by hand is detected and left alone — meta: fills gaps, it never duplicates.

  3. Check the sitemap

    Every build with prepros: set regenerates sitemap.xml at kirigami.root, one <url> per rendered page, from kirigami.baseurl — nothing to maintain by hand as pages get added or removed.

NOTE

This whole site runs on exactly this pair of blocks — every page you've read in this tutorial got its title, description and social card the same way, straight from its own PHPDOC.
