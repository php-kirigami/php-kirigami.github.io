Tools

The same engine behind four front doors. Pick the one that fits how you work; they build the same site.

  • CLI: kiri build, serve, export and the rest, from any terminal.
  • VS Code extension: build, export and preview from the editor's Command Palette and status bar.
  • MCP server: let an AI assistant build, validate and scaffold a project through the Model Context Protocol.
  • JavaScript API: load a project in your own Node code and call build(), export() or serve().

Every code block on this site is colored at build time by @kirigami/plugin-highlight: no highlighter reaches your browser.
